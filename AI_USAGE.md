# AI Usage

AI-assisted development tools were used during the development of this technical assignment.

## AI Tool Used

### ChatGPT

ChatGPT was used as a development assistance tool during the implementation of the application.

## Where AI Was Used

AI assistance was used for:

- Creating the React component structure.
- Developing the API service layer using Axios.
- Improving frontend component organization.
- Creating responsive CSS.
- Adding frontend form validation.
- Reviewing implementation decisions and code structure.
- Preparing project documentation.

## Why AI Was Used

AI was used to accelerate development and help structure the implementation while keeping the application simple and aligned with the assignment requirements.

The generated code was reviewed and tested during development rather than being submitted without understanding it.

## Example Prompts

Examples of prompts used during development include:

- "We need to Test a simple CRUD application using React and NestJS."
- "Create a React company form connected to the NestJS API."
- "Create a responsive UI for the company management application."

## Generated Code That Was Kept

AI-generated code was used as a starting point for:

- Companies service structure.
- React components.
- Axios API functions.
- Form validation.
- CSS styling.

The code was reviewed, adjusted, and tested against the application's actual requirements.

## Code That Was Modified

Several generated implementations were modified during development to match the actual application.

For example:

- The search endpoint was changed to use the `search` query parameter.
- The React search implementation was updated to match the backend API.
- The frontend component structure was refactored so that `App.tsx` manages company data while `CompanyTable` focuses on presentation.
- The CSS was customized to use a bright color palette.
- Validation behavior was adjusted to match the company fields and API requirements.

## Code That Was Rejected

Suggestions that were unnecessary for the scope of this assignment were not included.

The implementation intentionally avoids unnecessary architectural complexity such as introducing a separate service for every CRUD operation or adding state-management libraries for a small application.

## Understanding and Verification

The application was tested manually during development by verifying:

- Company creation.
- Company listing.
- Company search.
- Company deletion.
- PostgreSQL persistence.
- Frontend loading states.
- Error handling.
- Form validation.
- Responsive behavior.
